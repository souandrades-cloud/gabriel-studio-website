# Projeto

**Nome:** Gabriel Studio Website

**Cliente:** Gabriel Studio

**Tipo:** Site Institucional (Template Base)

**Status:** V3 concluída e publicada em produção (fechamento técnico na Sprint 16.4). Landing Page V1 publicada anteriormente na Sprint 11.

---

# Objetivo

Desenvolver o site institucional oficial da Gabriel Studio.

Este projeto também servirá como Template Base para todos os futuros sites desenvolvidos pela empresa.

Todo componente criado deve ser reutilizável.

---

# Público-alvo

Pequenas e médias empresas que desejam:

- Criar um site profissional
- Desenvolver Landing Pages
- Automatizar processos
- Implementar Inteligência Artificial
- Modernizar sua presença digital
