# Gabriel Studio Website

Site institucional oficial da Gabriel Studio.

Este projeto também funciona como Template Base para futuros sites desenvolvidos pela empresa.

---

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide Icons

---

## Scripts

Instalar dependências

```bash
npm install
```

Rodar ambiente local

```bash
npm run dev
```

Build

```bash
npm run build
```

Lint

```bash
npm run lint
```

## Organização

Cada seção da Home deve ser um componente independente.

Exemplo:

```
Navbar

Hero

Services

Process

Projects

About

CTA

Footer
```
